NRF24L01+ 테스트 결과

- NRF24L01 의 경우 Receiver 의 경우 NRF24L01 센서의 3.3v와 GND 사이에 10uF 의 캐패시터 연결하면 좀더 안정적이어서 NRF24L01+ 모델도 동일할 것이라 예상함.
- Sender 의 경우 캐패시터 상관없이 전송 성공
- 기본 코드로 송신 테스트시에 RF24_PA_MAX 로 하면 실패. RF24_PA_MIN 하면 성공. 캐패시터 연결하고 테스트 필요.
- 안테나 연결해도 장애물이 있으면 통신이 어려움. 거실을 두고 안방 - 서재간에도 통신이 잘 안됨. RF24_PA_MAX 환경으로 테스트 필요
- 스펙상으로는 개방된 공간에서 최대 1.1KM 정도인듯하지만 실제로 얼마나 통신이 가능할지 테스트는 못해봤음.
