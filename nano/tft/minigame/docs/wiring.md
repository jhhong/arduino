# 결선도 (Arduino Nano · MINI GAMES)

이 문서가 배선의 **원본**이다. `wiring.svg` 는 이 표를 그림으로 옮긴 것이므로,
핀을 바꿀 때는 이 표 → `core.h` → SVG 순으로 함께 고친다.

핀 번호의 근거는 `../core.h` 의 아래 정의다.

```c
#define TFT_CS      10
#define TFT_DC      9
#define TFT_RST     8
#define PUSH_BUTTON 2
#define JOY_X       A0
#define JOY_Y       A1
#define BUZZER      7

Adafruit_ST7735 tft = Adafruit_ST7735(TFT_CS, TFT_DC, TFT_RST);  // 하드웨어 SPI
```

## 1. TFT LCD (ST7735, 128x160)

3인자 생성자는 **하드웨어 SPI** 를 쓴다. SPI 핀은 보드가 정하므로 바꿀 수 없다.
(Nano = `eightanaloginputs` variant → `standard/pins_arduino.h` → MOSI 11 / SCK 13)

실제 연결된 상태다.

| 모듈 핀 | Nano | 다른 표기 | 뜻 / 역할 |
|---|---|---|---|
| `SCK` | **D13** | `SCL`, `CLK` | 클럭 신호. 하드웨어 SPI SCK, 변경 불가 |
| `SDA` | **D11** | `MOSI`, `DIN`, `SDI` | 데이터 신호. 하드웨어 SPI MOSI, 변경 불가 |
| `RESET` | **D8** | `RES`, `RST` | 리셋 신호 |
| `CS` | **D10** | `CE` | **C**hip **S**elect (칩 선택) |
| `A0` | **D9** | `RS`, `DC` | **A**ddress **S**elect = **R**egister **S**elect = **D**ata/**C**ommand.<br>지금 보내는 바이트가 데이터인지 명령인지 구분하는 선 |
| `VCC` | **5V** | | 모듈 전원 |
| `GND` | **GND** | | |
| `LED` | **3.3V** | `BL`, `BLK` | 백라이트. **연결하지 않으면 화면이 어두워서 보이지 않는다** |

> `A0` 는 아날로그 입력 A0 가 **아니다.** 모듈 제조사마다 `A0` / `RS` / `DC` 중
> 하나로 적어두는데 셋 다 같은 핀이다. 조이스틱이 진짜 아날로그 A0 를 쓰고
> 있으므로 배선할 때 특히 헷갈리기 쉽다.

`MISO`(D12)는 쓰지 않는다. 화면에 그리기만 하고 읽지 않기 때문이다.
D12 는 비어 있으므로 다른 용도로 써도 된다.

## 2. 조이스틱 (아날로그 2축)

| 모듈 핀 | Nano 핀 | 비고 |
|---|---|---|
| `VRx` | **A0** | `JOY_X` |
| `VRy` | **A1** | `JOY_Y` |
| `+5V` / `VCC` | 5V | |
| `GND` | GND | |
| `SW` | (미사용) | 아래 참고 |

부팅할 때 중립값을 측정해서 기준으로 쓴다(`calibrateJoystick()`).
**전원을 넣는 순간 조이스틱을 건드리면 기준이 틀어진다.** 그 경우 리셋하면 된다.

축 방향은 코드가 이렇게 가정한다. 반대로 움직이면 배선에서 `VRx`/`VRy` 를
바꾸거나 `core.h` 의 `joyLeftward()` / `joyDownward()` 부호를 뒤집는다.

```c
short joyLeftward() { return analogRead(JOY_X) - joyCenterX; }  // 양수 = 왼쪽
short joyDownward() { return joyCenterY - analogRead(JOY_Y); }  // 양수 = 아래쪽
```

## 3. 버튼

| 연결 | Nano 핀 |
|---|---|
| 버튼 한쪽 | **D2** |
| 버튼 반대쪽 | GND |

`pinMode(PUSH_BUTTON, INPUT_PULLUP)` 이므로 **외부 풀업 저항이 필요 없다.**
누르면 LOW 다.

조이스틱 모듈의 `SW` 핀도 눌렀을 때 GND 로 떨어지는 같은 구조라, 별도 버튼
대신 `SW` 를 D2 에 연결해도 그대로 동작한다.

## 4. 부저

| 모듈 핀 | Nano 핀 |
|---|---|
| `+` / `I/O` / `S` | **D7** |
| `-` / `GND` | GND |

`tone()` 을 쓴다. `tone()` 은 **Timer2** 를 점유하므로, 나중에 Timer2 를 쓰는
라이브러리를 추가하면 충돌한다.

능동형(active) 부저는 정해진 한 음만 나므로 음계가 필요하면 **수동형(passive)**
을 써야 한다.

## 전원

| 공급 | 연결된 것 |
|---|---|
| **5V** | TFT `VCC`, 조이스틱 `+5V`, 부저 `+` |
| **3.3V** | TFT `LED` (백라이트) |
| **GND** | 모든 모듈 공통 |

### 백라이트를 3.3V 에 문 이유

`LED` 는 백라이트 LED 를 그냥 켜는 핀이라 밝기 말고는 동작에 영향이 없다.
**연결하지 않으면 화면이 너무 어두워서 아무것도 보이지 않는다.**
(그림은 정상적으로 그려지고 있는 상태다. 조명만 꺼져 있는 것)

3.3V 에 물리면 5V 보다 어둡지만 LED 에 무리가 덜 간다. 모듈에 백라이트용
직렬 저항이 없는 개체도 있어서, 더 밝게 하고 싶어도 5V 직결보다는 저항을
끼우거나 PWM 핀에 물려 밝기를 조절하는 편이 안전하다.

주의할 점은 Nano 의 **3.3V 핀은 USB 시리얼 칩(FT232 / CH340)에서 나오는 것**
이라 공급 능력이 약하다는 것이다. 정품 Nano 기준 50mA 정도가 한계이고,
클론 보드는 이보다 못한 경우도 있다. 지금은 백라이트 하나뿐이라 문제가 없지만,
3.3V 에서 뭔가를 더 끌어쓰기 시작하면 화면이 깜빡이거나 리셋이 걸릴 수 있다.

### 신호선 레벨 (확인해두면 좋은 것)

ST7735 컨트롤러 자체는 **3.3V 로직**이다. `VCC` 에 5V 를 넣고 정상 동작한다는
것은 모듈에 3.3V 레귤레이터가 올라가 있다는 뜻이다. 다만 **레귤레이터가 있는
것과 신호선에 레벨시프터가 있는 것은 별개다.** 신호선 5개(SCK/SDA/RESET/CS/A0)에
5V 가 그대로 들어가는 모듈도 흔하다.

지금 잘 돌고 있으면 당장 손댈 일은 아니지만, 모듈 뒷면에 저항 배열이나
`74HC4050` 같은 칩이 없다면 규격을 넘겨 쓰는 중이라는 점은 알아두면 좋다.
길게 쓸 물건이면 신호선에 분압 저항을 넣는 것이 안전하다.
